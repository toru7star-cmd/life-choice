# 今日の選択 - 毎日の記録

毎日の自分の選択を記録し、カレンダーで振り返るためのスマートフォン向けPWA試作品です。

スマホを見る時間を減らし、現実の生活に使う時間を増やすことを目的としています。長時間アプリを使ってもらうことは目指していません。

## プロダクト原則

1. アプリはユーザーを評価しない
2. 正解を押し付けない
3. 何が良い行動かはユーザー自身が決める
4. アプリの利用時間を増やさない
5. 1回30秒以内で記録を完了できるようにする
6. 連続記録を強制しない
7. 記録できなかった日があっても責めない
8. ランキングや他人との比較は入れない
9. ログインボーナスや時間限定イベントは入れない
10. ユーザーがアプリに依存する設計にしない

## 使用技術

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui（Button / Card / Textarea / Input / Sheet / AlertDialog / Label）
- localStorage（データ永続化）
- PWA（Web App Manifest / Service Worker）

## セットアップ方法

Node.js がインストールされたWindows環境で、プロジェクトフォルダ内で依存パッケージをインストールします。

```bash
npm install
```

## 開発サーバーの起動方法

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。スマートフォンでの確認は、同一ネットワーク内の実機からPCのIPアドレス宛にアクセスするか、ブラウザの開発者ツールでモバイル表示に切り替えて確認してください。

> 注意: 開発モード（`next dev`）ではService WorkerはHMR（ホットリロード）と競合するため登録されません。Service Workerの動作確認は本番ビルド（`npm run build && npm run start`）で行ってください。

## ビルド方法

```bash
npm run build
npm run start
```

## データの保存場所

すべてのデータはサーバーに送信されず、ブラウザの `localStorage` にのみ保存されます。

- `mindful-log:records` … 日次記録（日付・選択・一言日記）
- `mindful-log:categories` … ユーザーが登録した分類項目

ブラウザのデータを削除すると記録も削除されます。他の端末とは同期されません。

## 現在実装している機能

- 今日の記録画面（3択アイコン選択 + 100文字以内の一言日記、1日1件・当日分は編集可）
- カレンダー画面（月表示、記録済み日にアイコン表示、日付タップで詳細表示・過去記録の編集）
- 自分の分類設定画面（3分類ごとに行動ラベルを追加・削除・並び替え、初期デフォルト値あり）
- PWA対応（ホーム画面への追加、本番ビルドでのオフラインキャッシュ）
